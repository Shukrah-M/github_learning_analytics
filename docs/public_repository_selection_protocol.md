# Public Repository Selection Protocol

## Purpose

Public GitHub repositories will be used to evaluate the behavioural
analytics system using naturally occurring development activity.

The public repositories are not assumed to provide direct evidence of
entrepreneurial learning. Their GitHub activity is analysed as a set of
behavioural proxies.

## Observation window

- Start: 2026-01-02T00:00:00Z
- End: 2026-07-01T00:00:00Z
- Duration: 180 days
- Start boundary: inclusive
- End boundary: exclusive

All selected repositories will be analysed using the same observation
period.

## Pilot sample

An initial pilot sample of five public repositories will be used to
validate the extraction and analysis process.

The final sample size will be confirmed after the pilot and supervisory
review.

## Inclusion criteria

A repository must:

1. Be publicly accessible.
2. Not be a fork.
3. Not be archived or disabled.
4. Have been created before 2 January 2026.
5. Contain commit activity during the observation window.
6. Represent a software product, prototype, service or application.
7. Have sufficient English-language documentation for manual screening.
8. Be accessible through the GitHub REST API.

## Exclusion criteria

A repository will be excluded if it is:

1. A fork, mirror or duplicated repository.
2. An archived or disabled repository.
3. Primarily a tutorial, course exercise or demonstration template.
4. Automatically generated or primarily maintained by bots.
5. Empty or without commits during the observation window.
6. Unrelated to product, prototype or application development.

## Ethical treatment

Repository owners and contributors will be pseudonymised in the
dissertation. Public usernames, email addresses and repository names
will not be used in the presentation of analytical results unless
methodologically necessary and ethically approved.
