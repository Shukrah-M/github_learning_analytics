Why this matters

Turning raw GitHub activity into evidence of entrepreneurial development usually means reading commit histories, issues and pull requests by hand. This dashboard automates that:

  • Behavioural metrics quantify iteration, persistence, problem-resolution and collaboration directly from commits, issues and pull requests.
  • The experimentation-intensity score gives one comparable figure per repository, so projects can be ranked and compared at a glance.
  • Automated text classification surfaces problem-solving, experimentation and refinement in commit messages, issue threads and reviews far faster than reading them one by one.
